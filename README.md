# Streamlit Demo App

This repository contains a minimal Streamlit example that demonstrates how to arrange widgets in columns. The left column displays a button, and the right column lets you pick a Hogwarts house from radio buttons and shows the selected house.

## Launching the App

Make sure you have Streamlit installed, then run:

```bash
streamlit run src/streamlit_app.py
```

This will start the Streamlit server and open the demo in your browser.
